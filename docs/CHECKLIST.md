# 12.2 내부 검증 체크리스트 (8단계)

기획서 12.2의 항목을 "자동으로 확인되는 것"과 "사람이 기기로 해 봐야 아는 것"으로 나눴다.
자동 항목은 테스트가 깨지면 바로 알 수 있다.

```bash
npx vitest run tests/progression.test.ts
```

위 명령은 본편 69스테이지를 화면 없이 처음부터 끝까지 두 번(동생 모드 · 누나 모드) 돌리고, 챕터마다 레벨 · 재화 · 패배 · 전투 시간을 출력한다.

## 시뮬레이션 조건

| | 동생 모드 | 누나 모드 |
|---|---|---|
| 난이도 | 스토리 | 보통 |
| 누르는 것 | "약점!" 표시가 뜬 스킬만, 나머지는 일반공격 | 약점·CP·오버클럭을 챙겨서 |
| 육성 | 안 함 (러너 1레벨 그대로) | 스토리 보상만으로. 매 스테이지 전에 "일괄 성장"(권장 레벨까지) + "추천 순서로 일괄 해금" |
| 편성 | 러너 + 체험 캐릭터 | 러너 + 1장 이후 다이브로 얻은 동료 3명(카이 · 미오 · 루나) |
| 소탕 · 반복 콘텐츠 | 안 함 | 안 함 |
| 카트리지 | 없음 | 없음 (실제로는 다이브로 생기므로 이보다 쉬움) |
| 시간 | 3배속, 한 번 누르는 데 1.3초 | 1배속, 한 번 고르는 데 2.2초 |

## 사람이 해 봐야 하는 것 (요약)

1. 아이패드 Safari: 홈 화면에 추가(PWA) → 첫 로딩 시간, 세로 한 손 전투, 소리(첫 터치 후 재생).
2. 맥북: 키보드 단축키 손맛, 스토리 전부 읽으면서 선택지가 고민되는지.
3. 두 기기에서 저장 → 새로고침 → 이어하기, 내보내기 · 가져오기.
