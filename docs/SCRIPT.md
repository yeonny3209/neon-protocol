# 대본 쓰는 법

대본은 `src/data/story/이름.txt` 파일 하나가 한 장면이야. 파일을 넣으면 코드를 건드리지 않고 바로 쓸 수 있어.
스테이지 데이터(`src/data/stages/*.json`)의 `pre`(전투 전)와 `post`(전투 후)에 파일 이름(확장자 없이)을 적으면 연결돼.

## 한 줄 한 줄

| 쓰는 법 | 뜻 |
|---|---|
| `이름: 대사` | 대사. 캐릭터 이름이 데이터에 있으면 그 캐릭터 그림이 나온다. `러너`는 플레이어가 정한 이름으로 보인다. |
| `이름[표정]: 대사` | 표정 `smile`(웃음) `angry`(화남) `sad`(슬픔). 안 쓰면 기본. |
| `* 글` | 나레이션 |
| `@bg 이름` | 배경 (`dump` `undertown` `market` `academy` `garden` `tower` `core` `black`) |
| `@bgm 이름` | 배경음 (`audio.json`과 `src/ui/bgm.ts`에 있는 곡 이름) |
| `@cg 이름` | 이벤트 일러스트. `@bg`를 쓰면 사라진다. |
| `@summary 글` | 이 줄부터 다음 `@summary`까지의 요약 한 줄. 스킵하면 "지난 이야기"로 보인다. 단락마다 하나씩 쓴다. |
| `@end` | 끝 (안 써도 파일 끝에서 끝난다) |
| `// 글` | 주석 |

## 선택지

```
@choice ch2_market big
- 암시장을 폭파한다 | nox+3 | set:true_ch2=1
- 기억을 주인에게 돌려준다 | white+3
- 의식 조각에게 맡긴다 | loop+3
```

- `@choice 아이디` 뒤에 `big`을 붙이면 큰 선택지(+3), 안 붙이면 작은 선택지(+1)야. 아이디는 게임 전체에서 겹치면 안 돼.
- `- ` 로 시작하는 줄이 선택지 하나. `|` 뒤에 효과를 붙인다.
  - `nox+3` `white+1` `loop+2`: 녹스트리트 / 화이트 노이즈 / 더 루프 신뢰도
  - `set:이름=1`: 플래그. 트루 엔딩 선택지는 `set:true_ch2=1`, `true_ch4`, `true_ch5` (2·4·5장에 하나씩)
  - `needs:A` `needs:B` `needs:C`: 그 엔딩이 열려 있을 때만 고를 수 있다
  - `ending:A` `ending:B` `ending:C`: 이 선택지가 엔딩을 결정한다
- 스킵 중에 선택지를 만나면 스킵이 멈추고 선택지만 보여 줘. 선택 자체는 건너뛰지 않아.

## 조건 분기

```
@if nox>=5
카이: 네가 이쪽 편이라서 다행이야.
@else
카이: …아직 널 다 믿는 건 아니야.
@endif
```

조건: `nox>=5` `white<2` `flag:이름` `!flag:이름` `highest:nox` `lowest:loop` `ending:A` `trueEnding`. `&&`로 이어 쓴다.

## 엔딩 규칙 (6장 마지막 선택지)

- 끄기(A): 녹스트리트 신뢰도 ≥ 화이트 노이즈일 때 고를 수 있다.
- 다시 쓰기(B): 화이트 노이즈 ≥ 녹스트리트일 때 고를 수 있다.
- 공존(C): 세 신뢰도가 모두 5 이상이고 `true_ch2` `true_ch4` `true_ch5`가 모두 켜져 있을 때.
- 기준값은 `balance.json`의 `story.trueTrust`.
- 신뢰도와 플래그는 선택 기록에서 다시 계산할 수 있어서, 엔딩을 본 뒤 챕터를 골라 선택지만 다시 고를 수 있다.
