그림·영상 올리기 GitHub 화면이 열려. 파일을 끌어다 놓고 아래쪽 초록색 "Commit changes"를 누르면 끝이야. 파일 이름이 그림 이름이 되니까 "카이_웃음.png"처럼 지어 줘.
링크 올리기 용량이 큰 영상은 파일 대신 링크로 올려 줘. 링크 한 개당 GitHub 화면이 한 번 열려.
